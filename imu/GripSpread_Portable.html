다른 컴퓨터에서 실행하는 방법
  1. Windows의 Chrome 또는 Edge에서 이 HTML 파일을 직접 엽니다. Bluetooth를 켜고 센서 전원을 켭니다.
  2. 기존 PC의 Python 수신기와 다른 BLE 앱의 연결을 해제합니다. 한 센서를 두 PC가 동시에 점유하지 않도록 합니다.
  3. 센서 연결을 누른 뒤 GripSpread-C3-MPU를 선택합니다. 컵을 세워 가만히 두면 기준 자세를 잡습니다.
  4. 연결되면 기록이 자동 시작됩니다. 연결 해제 후에도 CSV를 저장할 수 있습니다. 페이지를 닫기 전에 CSV를 저장하세요.

파일 직접 실행이 브라우저 정책에 막히면 HTTPS 또는 localhost에서 실행하세요. 일반 HTTP 주소와 앱 내 미리보기는 BLE를 지원하지 않을 수 있습니다. Safari·Firefox에서는 직접 BLE 연결을 지원하지 않습니다.

한 창의 기록 한도는 120,000개로 약 100Hz에서 20분 분량입니다. 한도에 도달하면 기록만 멈추고 화면 표시는 계속됩니다. CSV 저장 후 새 창에서 다음 기록을 시작하세요.
