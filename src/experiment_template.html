장비 확인

모든 참여자가 같은 기기, 같은 설정으로 해야 합니다. 기기 정보는 이 브라우저에 기억되고, 체크는 매 세션 새로 합니다.

macOS 기본값 그대로 씁니다. 아래 세 항목만 확인하세요. 터미널 defaults read -g com.apple.trackpad.scrolling → 0.3125 또는 "does not exist"면 기본값. 센서 없음 맥북 힌지의 각도 센서를 크롬으로 바로 읽습니다(창에서 Apple 기기를 고르면 됨). 목표 ±2° 안이면 초록. 센서가 없는 모델이면 아이폰 측정 앱 수평계를 화면 뒷면에 대고 15°가 나오게 맞춥니다. 카메라 준비 중…

과제 설정

컵 IMU

  1. 컵 센서 스위치를 켜고 을 누른 뒤 GripSpread-C3-MPU를 고릅니다.
  2. 센서를 받침에 새로 끼운 날만: IMU 보정 하기 (가만히 10초 → 6면 → 한 바퀴 두 번, 약 10분). 이전 보정이 있으면 자동으로 불러옵니다.
  3. 매 세션: 컵을 책상에 세워 두고 손을 뗀 채 정지 확인 10초.
또는 파일 불러오기

클라우드 자동 저장

켜 두면 조건이 끝날 때마다 가벼운 기록이, 실험이 끝나면 전체 데이터 zip이 Supabase에 올라갑니다. 로컬 zip 저장은 그대로 됩니다. 값은 이 브라우저에만 저장됩니다. publishable 키만 넣어 주세요(secret 키는 거부합니다). 쓰지 않으면 그냥 다음을 누르세요.

참여자 정보

참여자가 오면 시작합니다. 참여자 번호로 기법 순서와 컵 순서가 자동으로 정해집니다. 번호는 1번부터 순서대로 씁니다.

손 크기

주손을 실험자가 잽니다. 각각 두 번 재서 적으면 평균이 자동으로 계산됩니다. 두 값이 5mm 넘게 차이 나면 한 번 더 재서 가까운 두 값을 적습니다.

  • 손 길이: 손바닥이 위로, 손가락을 붙이고 펴서 책상에 놓습니다. 손바닥 쪽 첫 손목 주름에 자의 0을 맞추고 중지 끝(손톱 말고 살 끝)까지.
  • span: 손바닥이 아래로, A4 위에서 다섯 손가락을 최대한 벌립니다. 엄지 끝과 소지 끝에 펜으로 점을 찍고, 손을 뗀 뒤 두 점 사이를 잽니다.

배경 설문

여기부터는 참여자분이 직접 입력해 주세요. 정답은 없고, 해당하는 것을 고르시면 됩니다.
