# GripSpread 측정·분석 한눈에

이 문서 하나로 "무엇을, 어떤 조건에서, 어떻게 재고, 왜 재고, 어떻게 검정하는지"를 볼 수 있게 정리했다.

## 1. 실험 조건 (IV, 독립변수)

| IV | 수준 | 설명 |
| --- | --- | --- |
| 기법 | 트랙패드 / GripSpread (2) | 컵을 든 손으로 스크롤하는 방법 |
| 컵 | 없음 / 60 / 75 / 90 mm (4) | 컵 지름. 셋 다 센서 포함 190 g. "없음"은 각 기법의 성능 상한(오라클) |

- **피험자 내 설계:** 모든 참가자가 2 × 4 = 8조건을 다 한다.
- **순서 상쇄:** 기법 순서는 참가자 번호로 반씩, 컵 순서는 4×4 균형 라틴 방격.
- **과제:** 번호 붙은 줄 목록에서 주황색 목표 줄을 가운데 회색 영역에 넣고 멈추기. 거리 D = 400 / 1200 / 3600 px × 허용 폭 W = 40 / 120 px, 조합마다 반복(현재 6회, 파일럿 후 확정). 조건마다 적응 시행 2회는 분석에서 뺀다.
- **난이도 ID** = log₂(D/W + 1) → 2.1 / 3.5 / 5.0 / 6.5 bits (4가지).
- **분석 단위:** 참가자 × 조건마다 시행을 평균 낸 값 하나. 검정은 모든 조건이 있는 참가자만.

## 3. 공통 규칙

- **보고:** 평균은 항상 표준편차와 같이: 평균 (SD). 그래프 오차 막대는 ±1 SD. 설문은 중앙값도 같이.
- **반복측정 ANOVA:** 기법 × 컵 2요인. 컵처럼 수준이 3개 이상이면 Greenhouse–Geisser 보정(자유도가 소수로 나옴). 효과 크기는 부분 η².
- **사후검정:** ANOVA가 유의하면 컵마다 두 기법을 대응 t검정으로 비교하고 Holm 보정. 모든 쌍(28쌍)은 비교하지 않는다. 가설이 묻는 건 "어느 컵에서 두 기법이 다른가"이기 때문.
- **유의수준:** p < .05. 유의하지 않아도 보고한다.
- **이상한 시행:** 빼지 않고 표시만 한다(분석 페이지 "추가 점검"). 보고서에는 쓰지 않는다.
- **H1 오라클:** 처리량 손실은 같은 사람, 같은 기법의 "컵 없음"을 기준으로 계산하므로 손실 분석의 컵 수준은 60/75/90 세 개다.
- **IMU 지표:** 컵이 있어야 재므로 60/75/90 세 수준만.
