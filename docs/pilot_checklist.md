# 본 실험 파일럿 체크리스트 (11/11 수 · 11/12 목)

팀 밖 사람이 본 실험을 처음부터 끝까지 해 보면서 아래를 확인한다. 파일럿 참가자는 본 실험에 다시 못 나온다. 끝나면 맨 아래 "결정"을 적는다. (팀 공유용은 Claude 문서 "GripSpread 일정"에 같은 내용이 있다.)

## 시작 전
- [ ] 첫 화면에서 "파일럿"으로 들어가 상단에 파란 "본 실험 파일럿" 배지가 뜨는지
- [ ] 서버 자동 저장 "연결됨" + 업로드 테스트 성공
- [ ] 상수 보정 값이 서버에서 자동으로 불러와졌는지 (값 불러오기 줄에 "불러옴 (서버 …)")
- [ ] 컵 IMU 연결, 서버 보정 파일 적용, 정지 확인 10초
- [ ] 폰 녹화(웹캠과 같은 고각 정면), 참가자 서 있음, 컵 3개

## 진행 중 재고 적을 것
- [ ] 단계별 시간: 설명·보정 / 연습(기법당) / 측정 조건 하나 / 설문(TLX·ISO·SEQ) / 휴식 / 인터뷰 / 전체 → 반복 6·5·4회 결정에 씀
- [ ] 팔·손·손목 피로가 언제부터 보이는지, 쉬는 시간이 모자라지 않은지
- [ ] 연습 12–24회로 익숙해졌는지 (첫 측정 조건 앞부분에서 여전히 헤매는지)
- [ ] GripSpread 속도 반응: "너무 빠름", "자꾸 지나침", "너무 느림" 같은 말과 행동 (파일럿 2명이 같은 방향이면 상수 조정)
- [ ] 시작이 안 되거나(출발 잠금 150 ms) 먼저 움직이는 일
- [ ] 멈춤 판정: 맞췄는데 안 넘어가거나, 지나갔는데 성공으로 나오는 일
- [ ] 15초 초과 실패가 몇 번 나오는지
- [ ] 손 인식이 끊기는 일(조명, 손 각도), 컵 흔들림·흘림 걱정을 말하는지
- [ ] 설명을 다시 해야 했던 곳: 회색 영역, 주황 막대, 편한 V, 멈추기
- [ ] 설문에서 멈칫한 문항: TLX 시간적 요구, ISO 힘·속도(3이 적당), SEQ
- [ ] 인터뷰 질문이 자연스럽고 5분 안에 끝나는지

## 끝난 뒤
- [ ] 파일 관리: `pilot` 폴더에 최종 zip(`_final`)이 있고 `experiment` 폴더는 비어 있는지
- [ ] 로컬 zip 이름이 `PILOT_`으로 시작하는지
- [ ] 분석 페이지 "데이터: 본 실험 파일럿"으로 표·그림이 끝까지 나오는지, IMU 방향 경고 없는지, 확인할 시행 수
- [ ] 인터뷰 요약이 분석 페이지 "인터뷰 요약"에 나오는지

## 결정 (목요일 끝날 때 적기)
- [ ] 반복 횟수: 6 / 5 / 4회
- [ ] 상수 조정 여부 (조정하면 상수 보정 페이지에서 새로 저장)
- [ ] 지시문·설문·인터뷰 문구 수정
- [ ] 연습 횟수(12–24) 유지 여부
